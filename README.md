# PM.05# ✈ AeroAdmin — панель администратора авиабилетов

Информационная система для управления базой авиакомпаний, расписанием рейсов,
тарифами и бронированиями. Разработана в рамках производственной практики
ПМ.05 «Проектирование и разработка информационных систем».

## Стек
- Python 3.11+
- Flask 3
- SQLAlchemy + Flask-Login
- MySQL (в продакшене) / SQLite (по умолчанию)
- Jinja2, HTML/CSS

## Возможности
- Аутентификация администратора (хэширование паролей)
- CRUD авиакомпаний (с защитой от удаления связанных записей)
- Управление рейсами: добавление, редактирование, удаление, поиск, пагинация
- Обновление тарифов в один клик
- Управление бронированиями (фильтры, отмена)
- Статистика: выручка, средний чек, доля отмен, загрузка рейсов
- Кастомная страница 404

## Локальный запуск

```bash
git clone https://github.com/USERNAME/airline-admin.git
cd airline-admin
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux/macOS
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
# отредактируйте .env (DATABASE_URL, SECRET_KEY)

python run.py
